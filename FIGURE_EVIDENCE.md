# Figure Evidence Review — Frontend

**Reviewed:** 2026-11-02
**Scope:** Frontend implementation and figure-facing claims for the twelve proposed system figures. This is a source review, not a live-browser inspection. No browser page or production dataset was available for visual/data verification.

The backend calculation and API evidence is documented separately in [`nin-architecture/FIGURE_EVIDENCE.md`](../nin-architecture/FIGURE_EVIDENCE.md).

## Assessment terms

- **Present:** A corresponding frontend page, chart, or report exists in source.
- **Partial / caption correction needed:** A related view exists, but it does not support all claims in the proposed caption.
- **Not present as described:** No corresponding visualization or report was found in the inspected frontend.
- **Not verified:** Source code alone cannot establish live rendering, real-data correctness, official data provenance, or predictive accuracy.

## Recommended evidence to retain with screenshots

For each figure, retain the displayed screen and its date/time, analysis or forecast run identifier, selected filters, and the exact data/API response behind the displayed values. Redact personal or sensitive incident details. For geocoding, retain independently checked sample addresses/coordinates. For forecasts, retain a reproducible held-out validation report. A screenshot alone is visualization evidence, not proof of data provenance or computation correctness.
